# Sources des effets du lot 0.11

`effects-sheet.png` est une image **générée par IA pour ce projet**, pas une capture extraite d’un jeu. Elle propose flammes, sceaux, rochers, ondes, poing, fleur, nuée, loups, ombres, impact, croissant, pétales, colosse, lames, éclair et vent. Aucun personnage tiers ni texture téléchargée n’a été copié.

Le résultat a réellement six colonnes et trois rangées, malgré la demande initiale de seize cellules en 4 × 4. Il a donc été inspecté, découpé selon son organisation réelle, réordonné en seize cellules et détouré ; les deux motifs redondants sont exclus. Le script conserve les coordonnées de recadrage et les empreintes. La source est hors `game/`, jamais embarquée dans l’APK. Pas de service IA appelé pendant le jeu. Noms et rendus d’ultimes : propositions du prototype, non déblocages de compte.
