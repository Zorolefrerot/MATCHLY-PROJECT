# IDREM KARTGo — prototype

Ouvrir `/kartgo/` sur un serveur HTTP. La PWA peut être installée sur un site HTTPS (sur iPhone : Safari → Partager → Sur l’écran d’accueil). Après une première visite en ligne, ses ressources locales sont mises en cache pour les courses solo hors ligne.

Cette première étape est un prototype 3D solo : 3 décors, 7 bots, 3 tours, direction tactile ou clavier et turbo rechargeable. La trajectoire avance automatiquement. Les courses en ligne, les salons, l'authentification Google, le classement, les cosmétiques, le choix de kart, les objets variés et l'inclinaison ne sont pas encore implémentés. La traduction anglaise est partielle. Ne pas présenter ce prototype comme un jeu multijoueur complet.

Le moteur Three.js est distribué localement pour le fonctionnement hors ligne (licence MIT : https://github.com/mrdoob/three.js/blob/r170/LICENSE).
