# Rapport de validation — en cours

La validation locale du moteur et la compilation Android sont en cours. Ce fichier sera mis à jour avec les commandes et résultats réellement obtenus avant livraison.

Constats initiaux : aucun Godot, Blender, Java, SDK Android, ADB ou Gradle installé dans le sandbox. Aucun projet Godot existant dans le dépôt. Les téléchargements GitHub Release redirigent vers des hôtes bloqués ; les sources Godot 4.4.1 sont accessibles via codeload. Un moteur headless de test est compilé depuis ces sources ; il ne remplace pas une validation graphique GLES sur appareil.

Analyse syntaxique initiale des GDScript : réussie avec gdtoolkit. Cela ne constitue pas une preuve de compilation Godot, de jouabilité ou de compatibilité Android.
